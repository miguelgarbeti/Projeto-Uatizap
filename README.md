# 💬 Registro de Usuários e Autenticação – WhatsApp

## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver funcionalidades de registro de novos usuários e autenticação em um sistema de mensagens inspirado no WhatsApp. A aplicação utiliza HTML, CSS e JavaScript no frontend, Node.js e Express no backend, além do MySQL para armazenar os dados dos usuários.

## 🚀 Funcionalidades

- **Cadastro de usuários:** permite criar uma conta informando telefone, nome e senha.
- **Autenticação:** verifica as credenciais para permitir o acesso ao sistema.
- **Integração com API:** realiza requisições HTTP para enviar e consultar informações.
- **Banco de dados:** armazena os dados utilizando MySQL.
- **Interface web:** apresenta páginas de cadastro e login inspiradas no WhatsApp.

## ⚙️ Como Executar

1. Instale o Node.js e o MySQL.
2. Clone este repositório.
3. Execute `npm install` para instalar as dependências.
4. Configure a conexão com o banco de dados MySQL.
5. Inicie o servidor da API.
6. Abra a página `index.html` para acessar o login.
